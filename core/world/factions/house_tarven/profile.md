# Дом Тарвен

Название: дом Тарвен
Тип: городской дом влияния / долговая сила
Методы: старые взыскания, управители долгов, судебные описи, посредники.
Публичный статус: уважаемый или по крайней мере законный дом; точный статус пока не установлен.
Степень известности: неполные сведения.
Связь с историей: через Эрсана Тарвенского связан со старыми взысканиями по дому Хрода и текущей охотой за черным клинком.
Связанные персонажи: Эрсан Тарвенский, Кайр Рыжий, Батуй, Марек, Ойвен.
