# Артефакты

Важные предметы, реликвии, проклятые вещи и магические объекты.

## Компактизация

Общие правила сжатия канона находятся в `core/world/COMPACTION.md`.

При компактизации артефакта:

- обновить, где он находится;
- кто его несет, ищет или охраняет;
- какие свойства действительно известны персонажам;
- какие слухи устарели или были опровергнуты;
- какие детали нужно оставить скрытыми до подтверждения в игре.
