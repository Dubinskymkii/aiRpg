# Главные Персонажи

Главные персонажи двигают сюжет или раскрывают важные слои мира.

## Шаблон

```text
Имя:
Роль:
Важные цели:
Текущие цели:
Страх:
Что знает из недавней истории:
Что знает из средней истории:
Что знает из мифологии:
Что скрывает:
Отношение к игроку:
Долговременная память:
Кратковременная память:
Последнее изменение:
Связанные места:
Связанные фракции:
```
