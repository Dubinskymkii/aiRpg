# World Structure

This directory contains shared instructions and schemas only. It must not contain canon from a playable campaign.

Campaign-owned data lives under:

```text
campaigns/<campaign_id>/
  CAMPAIGN.md
  assets/
  world/
    artifacts/
    characters/
    factions/
    history/
    places/
    sessions/
  saves/
```

The active campaign is selected through `.airpg/ACTIVE_CAMPAIGN`.
