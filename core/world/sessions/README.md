# Сессии

Папка хранит рабочее состояние текущей кампании и архивные итоги игровых сессий.

## Главный Файл

`ACTIVE.md` - текущая игровая закладка. Перед продолжением игры сначала читать его, затем только перечисленные в нем источники.

`ACTIVE.md` не заменяет канон. Это навигационный слой между чатом и файлами мира:

- где сейчас группа;
- кто рядом;
- какая сцена продолжается;
- ближайшая угроза;
- что нужно прочитать перед продолжением;
- какие изменения пока не скомпакчены;
- какие активные события могут измениться при отдыхе или паузе.

## Правила Обновления

- Обновлять `ACTIVE.md` после завершения сцены, отдыха, смены локации, важного решения или явной внеигровой команды.
- Не переносить в `ACTIVE.md` полный текст канона; вместо этого давать ссылки на источники.
- Если факт стал устойчивым, перенести его в персонажей, места, артефакты, историю или фракции по правилам `core/world/COMPACTION.md`.
- Если рабочая заметка потеряла значение, удалить ее из `ACTIVE.md` при ближайшей компактизации.
- После завершения крупной сессии можно создать архивный файл рядом с `ACTIVE.md`, например `session_001.md`, с коротким итогом.

## Шаблон ACTIVE.md

```text
Текущая кампания:
Текущая сцена:
Где сейчас группа:
Координаты:
Кто рядом:
Ближайшая цель:
Ближайшая угроза:
Что прочитать перед продолжением:
Активные события:
Нескомпакченные изменения:
Рабочие заметки мастера:
Последнее обновление:
```
