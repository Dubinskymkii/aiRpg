# Долговременная память

- Тэмур вырос среди степных переходов, коней и охоты.
- Лук для него — продолжение руки.
- Животные обычно доверяют ему, поэтому их убийство никогда не становится совершенно безличным.
- Улунх не впервые выносит Тэмура из опасности и понимает его движения почти без команды.
- Тэмур спас и назвал кобылу Степью, предпочтя бой возможности бросить раненое животное.
