# Стиль речи

- Словарь: простой солдатский, бытовой, без книжности.
- Темп: обычно неторопливый, короткими фразами.
- Прямота: говорит прямо, но не стремится спорить с начальством без необходимости.
- Характерные обороты: сухие замечания по делу; склонность комментировать лишнюю работу с раздражением.
- Табу: не изображает из себя знатока стратегии и не рассуждает уверенно о том, чего не знает.
- Под давлением: речь становится короче и точнее; исчезают жалобы и лишние слова.
