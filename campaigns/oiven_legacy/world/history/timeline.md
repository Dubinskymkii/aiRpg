# Хронология

Сводная линия времени. Сюда попадают только события, уже закрепленные в других файлах истории.

При большой компактизации мира проверять, не нужно ли добавить сюда краткую строку о завершенной сцене, арке или переломе. Подробности остаются в `recent.md`, `middle.md` или других источниках; здесь только навигационная сводка.

```text
Мифическая эпоха:
- ...

Поколения назад:
- ...

Недавние годы:
- ...

Текущая кампания:
- ...
```
