# Операции

- Старая свечная мастерская у белильных ям: скрытый пункт обмена, сторожевой мальчик, серые свечи и тканевые узлы.
- Старый склад счетных досок: возможная ловушка для искателей долговых бумаг.
- Сбор похоронных записей и списков мастеров.
- Наблюдение за теми, кто произносит или записывает имя Хрода.
