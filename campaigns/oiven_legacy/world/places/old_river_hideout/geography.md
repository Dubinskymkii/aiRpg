# География

Координаты: `(6, 0)` на текущей городской сетке; можно уточнить.
Физическое состояние: старое русло с холодной водой, низкими укрытиями, мокрыми настилами и скрытыми комнатами.
Ближайшие места:
- Соляные склады: около 1 клетки по воде.
- Храмовые архивы Мер: около 3-4 клеток по прямой, реальный путь длиннее.
Ориентировочное время пути:
- От соляных складов: 5-10 минут с проводником.
- До храмовых архивов Мер: 15-25 минут осторожно с проводником; 25-40 минут с раненым Ойвеном и обходом судебных постов.
Маршруты:
- По воде через старые сваи и темные проходы.
- К храмовым архивам: сначала водой к тихому сходу, затем дворами; прямые подходы могут быть перекрыты судебными людьми.
Географические изменения:
- Пока не установлены.
